# 분류 체계 데이터

**2단계 API** (`POST /api/analyze-duplicates`)가 `taxonomy.json`을 읽어 프롬프트에 넣고, 응답의 `trade` / `majorCategory` / `minorCategory`를 **허용 목록으로 검증·보정**합니다.

## 파일

| 파일 | 설명 |
|------|------|
| `taxonomy.json` | **여기만 수정**하면 됩니다. 공종 → 대분류 → 소분류 트리 |

## 구조 요약

- **`fallback`**: AI·규칙이 어긋났을 때 쓸 기본값(보통 `기타`).
- **`trades`**: 공종 단위.
  - 각 공종마다 **`majors`(대분류)** 목록.
  - 각 대분류마다 **`minors`(소분류)** 목록.
- **`id` / `label`**: 지금은 동일한 문자열로 두었습니다. 나중에 코드에서 `id`로 매칭하고 `label`만 화면에 쓰도록 분리할 수 있습니다.

## 편집 시 주의

1. JSON 문법: 마지막 항목 뒤 **쉼표 없음**, 큰따옴표만 사용.
2. 분류명에 **하이픈 `-`** 이 많이 들어가면, 나중에 `groupKey`를 `"공종-대분류-소분류"` 한 줄로 쓸 때 파싱이 꼬일 수 있습니다. 가능하면 **중점 `·` 또는 공백**을 쓰는 편이 안전합니다.
3. 백업: 큰 수정 전에 `taxonomy.json`을 복사해 두세요.

## 다른 경로의 JSON을 쓰려면

프로젝트 루트 `.env.local` 등에 다음을 설정합니다.

`CLASSIFICATION_TAXONOMY_PATH` = 절대 또는 상대 경로 (예: `D:\\data\\my-taxonomy.json`)
